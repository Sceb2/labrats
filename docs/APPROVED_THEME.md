# Approved LabRats theme

Approved for both main and development on 28 October 2026.

White page #ffffff; body text #18251e; navigation and primary actions #105640;
active/hover navigation #286049; gold navigation marker #e4b735; finish actions
#795337; dividers #d2dad4; flashcard face #fffefa and border #d1ded2.

Open Sans Bold supplies page titles. Liberation Sans supplies body text,
questions, flashcards, controls, navigation and badges. DejaVu Serif supplies
topic/subject names, feedback headings and secondary details. The latter is an
approved serif approximation of the earlier Rockwell selection. Navigation and
buttons use the approved sans-serif revision. Existing feedback/grade semantics
and pink Not yet control are preserved.

Font files are distributed unchanged with their licences under assets/fonts.
fonts.css loads those files from the same site. Standalone previews embed their
font bytes with a font-src data: policy, requiring no third-party font service.
The release fingerprint includes the font files and stylesheet.

This theme changes no database schema or account/marking/adaptive behaviour.
