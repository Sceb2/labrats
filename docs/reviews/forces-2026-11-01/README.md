# Forces draft: specification review updates

The 124-question teacher-review draft extends the existing pack with 14 original, automatically marked application questions. It remains separate from the live question bank and does not use student accounts or hosted Supabase.

The new material covers airbags and stopping time, safety features, impact forces and force–time graphs, displacement–time and velocity–time graphs, trolley measurements, speed and fuel use, falling through a liquid, friction, and rigid passenger cells. The questions use scaffolded selected answers and calculations intentionally; they are revision practice, not claims about the exact format of Pearson examination questions.

Existing question amendments include force direction and balanced forces, acceptable rounded weight calculations, carrying both earlier values into a speed calculation, momentum magnitudes, more relevant hints, plausible safety-feature distractors and practical measurement apparatus. The shared marking engine now supports explicitly listed acceptable rounded answers and division using two earlier responses; existing questions only use these features when configured to do so.

Scope was checked against the uploaded Pearson AAQ Applied Science Certificate specification, Issue 5 (May 2026), printed pages 50–52, alongside the uploaded Extended Certificate sample assessment, May 2026 Unit 3 question paper and examiner report. The resulting questions are original revision material; the draft's marks and AO proportions are not official Pearson weightings. A teacher should review scientific content and suitability before publishing.
